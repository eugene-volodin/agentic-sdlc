# Architecture decision records

Short records of the decisions that shape this repository: what was decided, why, and what was rejected. A new
record copies [`template.md`](template.md) and takes the next number.

| # | Decision | Status |
|---|---|---|
| [0001](0001-pdf-through-chrome.md) | The PDF is printed by Google Chrome | Accepted |
| [0002](0002-vectors-only.md) | Everything in the PDF is a vector, set in the book's own fonts | Accepted |
| [0003](0003-licenses.md) | Different licenses for the text, the examples, the tool and the fonts | Accepted |
| [0004](0004-one-release-per-change.md) | Every change to the book is a release, and one link always gives the newest | Accepted |
