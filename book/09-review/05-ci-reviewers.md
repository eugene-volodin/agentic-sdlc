## Агенты-ревьюеры в CI

Ревьюить свой код локально, конечно же, стоит, только агента нужно не забыть об этом попросить, а даже если ревью прописано в его скиллах, оно всё равно может не запуститься. Например, когда:

- ты попросил агента поправить одну строчку и сразу запушить;
- агент не понял, что скилл ревью подходит к этой задаче, и не запустил его;
- кто-то из команды поправил код руками, без агента.

Поэтому у тебя обязательно должен стоять ревьюер в CI, который точно запустится на каждый пул-реквест и которого никто не сможет пропустить. Такой ревьюер оставляет комментарии к строчкам кода и пишет сводку по всему пул-реквесту, а дальше автор пул-реквеста или его агент правит код и отвечает на замечания.

Готовых ревьюеров, которых можно настроить на автоматический запуск у себя в CI, сейчас много. Одни работают только с GitHub, другие умеют проверять и self-hosted GitLab, то есть GitLab, который компания держит на своих серверах, а некоторые ревьюеры можно и вовсе развернуть у себя. Вот сводная таблица самых известных ревьюеров — где каждый работает, можно ли развернуть его у себя и сколько он стоит:

| Ревьюер | Где работает | Можно развернуть у себя | Сколько стоит |
|---|---|---|---|
| Claude Code Review | GitHub, и GitHub Enterprise Server тоже | нет | на тарифах Claude Team и Enterprise, платишь за токены |
| CodeRabbit | GitHub, GitLab, Bitbucket, Azure DevOps | на тарифе Enterprise от 500 мест | бесплатно для публичных репозиториев, от $24 в месяц за разработчика при оплате за год |
| Codex | GitHub, GitLab (в бете), и self-hosted GitLab тоже | нет | входит в подписку ChatGPT, ревью в GitHub — с тарифа Plus |
| Copilot | GitHub, Azure DevOps (в превью) | нет | от $10 в месяц, каждое ревью списывается из лимита тарифа |
| GitLab Duo | GitLab, и self-hosted тоже | да, вместе с GitLab | уже на бесплатном тарифе, ревью оплачивается кредитами GitLab |
| Cursor Bugbot | GitHub, GitLab, Bitbucket, Azure DevOps, и self-hosted тоже | нет | за каждый запуск, от $1 до $1,5 |
| Greptile | GitHub, GitLab, Bitbucket | на тарифе Enterprise | ревью стоит 1, 3 или 10 кредитов в зависимости от тарифа, кредит — $1 |
| PR-Agent | GitHub, GitLab, Bitbucket, Azure DevOps | да, это открытый код | открытый код, нужен свой ключ к модели |

Если код лежит в GitHub, проще всего начать с любого готового ревьюера из таблицы. А если у тебя self-hosted GitLab, то выбирай из тех, что с ним работают, или пиши своего ревьюера (о нём — в следующем разделе).

::: say cat
Если тарифа Team или Enterprise у тебя нет, в самом Claude Code есть встроенная команда `/code-review`, и она работает на любом тарифе. С флагом `--comment` Claude Code оставит замечания комментариями в пул-реквесте GitHub или одним общим комментарием в мерж-реквесте GitLab — [code.claude.com](https://code.claude.com/docs/en/code-review-local)
:::

Некоторые ревьюеры, например CodeRabbit и Copilot, позволяют в настройках включить автоматический аппрув после ревью, если критичных проблем нет. Только включать эту настройку я не рекомендую, потому что аппрув должны ставить люди, а ревьюер в CI действует не от имени какого-то человека и нести ответственность не может.

Правила, по которым проводить ревью, разные ревьюеры берут из разных мест:

- Codex, Copilot и CodeRabbit читают `AGENTS.md`;
- Claude Code Review — `CLAUDE.md` и свой `REVIEW.md`;
- Bugbot — `.cursor/BUGBOT.md`;
- GitLab Duo — `.gitlab/duo/mr-review-instructions.yaml`.

Если эти файлы со временем разойдутся с `AGENTS.md`, то агент будет писать код по одним правилам, а ревьюер — проверять по другим. Поэтому в файл ревьюера, например в `REVIEW.md` или `.cursor/BUGBOT.md`, клади только то, что касается самого ревью, а общие правила проекта пусть остаются в `AGENTS.md`. В документации Claude Code Review про `AGENTS.md` ничего не сказано, поэтому корневой `AGENTS.md` лучше подключить прямо в `REVIEW.md` строкой `@AGENTS.md`. Только `AGENTS.md` должен лежать в корне репозитория, а сработает эта строчка лишь тогда, когда ветка `main` защищена, то есть в её настройках включён branch protection или ruleset, который требует пул-реквест с аппрувом. Иначе Claude Code Review прочитает `@AGENTS.md` как обычный текст.

На ответы к своим замечаниям ревьюеры тоже реагируют по-разному:

- CodeRabbit отвечает, если упомянуть его в обсуждении, и запоминает, что тебе важно, а что нет;
- Claude Code Review по умолчанию проверяет пул-реквест заново после каждого пуша, и тогда же читает ответы на свои прошлые замечания — может закрыть обсуждение или ответить ещё раз;
- Copilot твоих ответов не видит вовсе: даже когда ты снова запросишь у него ревью этого же пул-реквеста, он может повторить замечания, которые ты уже закрыл.
