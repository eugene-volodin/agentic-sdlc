## Сначала были тулы

Чтобы понять, что такое MCP, вернёмся к тому, как устроен агент. По сути, агент — это цикл, который снова и снова вызывает модель и умеет выполнять какой-то набор **тулов** (tool — от английского «инструмент»). Тул — это просто функция или команда с набором аргументов и описанием того, что она делает, и у каждого агента такой набор свой, а агенты, которые занимаются написанием кода, например, умеют читать файлы, записывать в них код и запускать команды в терминале.

::: note cat
В документации Anthropic тул для Claude описывается тремя полями — именем, описанием и списком аргументов — [platform.claude.com](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)
:::

Когда агент вызывает модель, он передаёт ей в контексте список всех своих тулов, и модель, читая его, понимает, что она вообще может делать.

```json title="Так тул выглядит для модели"
{
  "name": "read_file",
  "description": "Читает файл из репозитория и возвращает его содержимое",
  "input_schema": {
    "type": "object",
    "properties": { "path": { "type": "string" } },
    "required": ["path"]
  }
}
```

::: note cat
Модели Claude официально умеют вызывать тулы с 30 мая 2024 года — [claude.com](https://claude.com/blog/tool-use-ga)
:::

Если модели не хватает данных, но взять их можно из какого-то тула, она просто отвечает агенту «вызови такой-то тул с такими-то аргументами». Агент его вызывает, получает результат и отправляет обратно модели, та его читает, и цикл повторяется, пока данных ей не станет достаточно.

Только вот список этих тулов заранее определён и захардкожен в самом агенте, так что о твоём Sentry или Datadog и их возможностях агент может ничего и не знать.
