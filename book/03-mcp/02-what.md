## Что такое MCP

::: note cat
Последняя версия стандарта вышла 28 июля 2026 года — [modelcontextprotocol.io](https://modelcontextprotocol.io/specification/latest)
:::

**MCP**, Model Context Protocol, — это открытый стандарт, который превращает набор тулов в подключаемый интерфейс. Ты подключаешь к агенту внешний **MCP-сервер**, и тот первым делом отдаёт ему список своих тулов с описанием. Агент подсовывает их в контекст модели рядом со своими тулами, и теперь модель может вызывать их ровно так же, как и обычные, захардкоженные тулы агента.

Придумали MCP Дэвид Сориа Парра и Джастин Спар-Саммерс, инженеры из Anthropic, и открыли его для всех в ноябре 2024 года, а в декабре 2025-го Anthropic передала его в Agentic AI Foundation при Linux Foundation.

::: note cat
Агент и MCP-сервер обмениваются сообщениями в формате JSON-RPC — с удалённым сервером по HTTP, а с локальным через стандартные потоки ввода и вывода — [modelcontextprotocol.io](https://modelcontextprotocol.io/specification/latest/basic/transports)
:::

Причём модель даже не знает, что какой-то тул живёт где-то снаружи, — всем этим занимается агент. Модель просто говорит, что хочет вызвать тул с такими-то аргументами, а агент сам понимает, где этот тул находится и как его вызвать: отправить запрос на удалённый сервер по HTTP или запустить у тебя на компьютере локальный исполняемый файл, передать данные в его стандартный поток ввода (stdin) и прочитать ответ из стандартного потока вывода (stdout). Отсюда и две разновидности MCP-серверов.

| Удалённые — живут у самого сервиса, подключаешься по URL | Локальные — агент сам запускает их у тебя на компьютере |
|---|---|
| - Sentry — ошибки<br>- Linear — задачи<br>- Atlassian — Jira и Confluence<br>- Notion — документы<br>- Figma — макеты<br>- GitHub — репозитории<br>- Supabase — база данных<br>- Datadog — логи и метрики<br>- Stripe — платежи<br>- Amplitude — продуктовая аналитика | - Playwright — управляет браузером<br>- Chrome DevTools — отладка в Chrome<br>- Firebase — база, пользователи и деплой<br>- Grafana — метрики и логи |

::: say professor
А ещё MCP-сервер может отдавать **ресурсы** — данные, которые можно подложить модели в контекст, — и **промпты**, заготовки запросов. Claude Code подставляет ресурс через `@`, а промпт запускает как слеш-команду
:::
